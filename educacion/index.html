Somos Bi2 — Soluciones ERP en la nube

Somos una empresa que ofrece soluciones personalizadas de ERP en la nube y bots automatizados para transformar y optimizar tu negocio. Nuestro sistema educativo es un ERP completo desarrollado con React + TypeScript + Firebase, diseñado para que instituciones gestionen toda su operación desde una sola plataforma, con soporte para múltiples escuelas (multi-tenant).
